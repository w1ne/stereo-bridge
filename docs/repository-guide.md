# Repository presentation decisions

The landing README answers what the app does, why separate channels help, how to start and which release is actually available. Detailed usage, compatibility, architecture and build guides have their own pages, with a documentation index and source map.

Examples reviewed:

- [Fossify Camera](https://github.com/FossifyOrg/Camera/blob/main/README.md): communicate privacy and ordinary app usage near the beginning.
- [OpenCamera-Sensors](https://github.com/prime-slam/OpenCamera-Sensors): explain the recording use case and offer direct installation and documentation paths.
- [Open Camera](https://opencamera.sourceforge.io/): describe practical camera capabilities and be honest about device validation.

These are presentation references, not endorsements or code dependencies. Stereo Bridge's README uses its own wording and reports current release and hardware limits explicitly.
